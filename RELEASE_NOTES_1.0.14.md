# Lampa Desktop 1.0.14

- Ядро sing-box заменено на 1.14.2-lx.10-custom: официальный 1.14.2-lx.10 плюс локальные доработки URLTest (активная проверка выбранного узла и возврат на более приоритетный) и XHTTP (числовые диапазоны, короткие session ID). Лимит XMUX по умолчанию оставлен официальным: не больше трёх соединений.
- Если установщик обновления уже скачан, окно установки показывается при каждом запуске. «Отложить» действует только до следующего запуска. Уведомление в трее повторяется с интервалом проверки приложения.
