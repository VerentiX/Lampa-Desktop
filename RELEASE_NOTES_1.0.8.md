# Lampa Desktop 1.0.8

- Bootstrap DNS и загрузка удалённых SRS-правил теперь используют системный резолвер Windows.
- Убрана обязательная зависимость запуска от доступности `1.1.1.1:53` по UDP.
- Cloudflare DoH через VPN и Яндекс DoH напрямую сохранены как защищённые DNS-маршруты для пользовательского трафика.
