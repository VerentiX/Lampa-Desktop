# Lampa Desktop 1.0.9

- Маршрутизация переведена с `AsIs` на `IPIfNonMatch` во всех встроенных профилях.
- В активном sing-box-конфиге добавлен эквивалент `IPIfNonMatch`: после несовпадения доменных правил ядро резолвит адрес и повторно проверяет IP-наборы перед выбором финального маршрута.
- Исправлен обход IP-списков для соединений, изначально открываемых по доменному имени.
- Добавлен выключенный по умолчанию «Режим белых списков»: без него маршруты P5+ полностью исключаются из конфигурации ядра, а при включении снова становятся доступны.
- В правом верхнем углу настроек теперь отображается фактически выбранный активный маршрут.
