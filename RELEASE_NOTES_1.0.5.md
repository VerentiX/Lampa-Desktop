# Lampa Desktop 1.0.5

- Новый техно-интерфейс и оригинальный персонаж-джинн.
- Новая прозрачная иконка приложения, трея и установщика.
- Кастомное ядро sing-box-lx 1.14.0-lx.29 и удалённые SRS-правила.
- Полная маршрутизация P0–P4 и whitelist-режим P5+.
- Одноразовое принудительное обновление старой подписки с User-Agent `Lampa-Desktop-SB`.
- Перед запуском завершается оставшийся процесс ядра именно этой установки Lampa.
- Исправлен запуск приложения после установки: Windows запрашивает повышение прав вместо ошибки 740.
- Проверены конфигурация, загрузка подписки и реальный старт ядра.

SHA-256 установщика публикуется в описании GitHub Release.
